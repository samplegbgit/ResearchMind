# ResearchMind 🔎

An AI-powered research assistant that searches the web, gathers relevant information, and generates concise research reports with AI-powered review.

## ✨ Features
- **Web Search:** Retrieves relevant information using Tavily.
- **Web Scraping:** Extracts useful content from web pages.
- **AI Research:** Uses AI agents to collect and analyze information.
- **Report Generation:** Generates structured research reports.
- **AI Critic:** Reviews reports and provides feedback.
- **Download Report:** Save generated research reports.

## 🛠️ Tech Stack
- **Language:** Python
- **Frontend:** Streamlit
- **LLM:** Groq
- **Agent Framework:** LangChain
- **Web Search:** Tavily API
- **Web Scraping:** BeautifulSoup, Requests
- **Deployment:** Render

## 🚀 Live Demo
[**Try ResearchMind**](https://researchmind-wdvr.onrender.com)

## 🔐 Environment Variables
Configure `GROQ_API_KEY` and `TAVILY_API_KEY` in your deployment environment.
